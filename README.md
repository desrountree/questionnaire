# questionnaire

Built pages only. They are made by the brand guidelines template (`python3 build.py _default --doc questionnaire`): edit the source and rebuild, never edit here.

- `/` the full questionnaire, for a client doing it all by link
- `/homework` the same without the brief, for after a coffee or call
- `/meeting` the brief only, the agenda for that coffee or call

Every page asks search engines not to list it.
